💬 Ask the knowledge base

Pick a question. The answer shows what is true and, if you want, why: which AWR data and which rules lead to it.

✏️ Write your own question in logic

A question is a list of conditions separated by commas (a comma means and). The app finds every way to make them all true.

  • NeedsOptimization(K): which keywords K need work? Words starting with a capital letter are blanks to fill in.
  • BeatenBy(K, C): which competitor C beats us on keyword K?
  • not Dropped(K): K did not drop.
  • Ranking(K, P), P < 4: compare numbers with < > <= >=; calculate with D is P - P0.
  • Priority('banana bread', P): put real keywords in quotes.

All the words you can use are listed in the Rules tab.

📘 How to read the rules

📄 Facts

Things AWR told us. Ranking('banana bread', 1) means “we rank #1 for banana bread”. CompetitorRanking(K, C, P) means “competitor C ranks #P for keyword K”.

🧠 Rules

“If … then …” statements. A :- B, C. reads “A is true if B and C are true”. The app keeps applying every rule to the facts until nothing new comes out.

🔤 Capital letters

Blanks to fill in: K = any keyword, P = a position, C = a competitor, G = a keyword group. A rule works for every value that fits.

🚫 “not”

not Dropped(K) means “nothing in the data shows K dropped”. If something can't be shown, it counts as false. This is called the closed-world assumption.

🧱 Strata (layers)

You can only say “K did not drop” after you've finished finding every keyword that did drop. So the rules run in layers (one layer is a stratum, several are strata). Layer 0 works from the facts; each later layer may use “not” about things earlier layers have fully worked out.

🔣 Symbols in the logic

∀ for every · ∧ and · ¬ not · → then · :- if. Example: ∀K (Dropped(K) → NeedsOptimization(K)) = “every keyword that dropped needs work”.
